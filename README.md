# TACI Official Website — Free Static Website

This is a mobile-friendly static website starter for TriArc Community Initiative (TACI).

## Files
- `index.html` — website content and sections
- `styles.css` — responsive design
- `script.js` — mobile navigation and contact form behaviour

## Before publishing
1. TACI's public email (`triarccommunityinitiave@gmail.com`) is already configured in `script.js` and displayed on the contact section.
2. Add TACI's approved telephone number in the contact section in `index.html`.
3. Add the exact registered name and registration number only if you want them public and have verified their wording.
4. Replace gallery placeholders with real, consent-approved project photographs.
5. Add verified news and project details. Do not present planned work as completed work.
6. Publish official donation instructions only after they have been approved and verified. This template does not accept or process payments.

## Publish free using GitHub Pages
1. Create/sign in to a GitHub account and create a new public repository, for example `taci-website`.
2. Upload `index.html`, `styles.css`, `script.js`, and `README.md` to the repository root.
3. Open repository **Settings → Pages**.
4. Under build/deployment, choose **Deploy from a branch**, select `main` and `/(root)`, then save.
5. Follow the Pages status/link shown by GitHub. The free address will use the format `https://YOUR-USERNAME.github.io/taci-website/`.

The exact availability and publishing steps are controlled by GitHub and may change. This package is ready to upload, but it has not itself been published online. You need access to the organisation's chosen hosting account to publish it.
